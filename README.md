#Adega Agnello

A Vinheria Agnello é uma empresa familiar que trabalha com a venda de vinhos há mais de 15 anos. A empresa sempre teve como diferencial o atendimento personalizado, ajudando os clientes a escolherem os vinhos de acordo com seus gostos e com cada ocasião.

Com a pandemia, o movimento da loja física caiu bastante e muitos clientes passaram a comprar pela internet. Por isso, a Vinheria decidiu criar uma loja virtual. O principal desafio é fazer com que o site mantenha, mesmo online, a experiência de atendimento e orientação que os clientes encontram na loja física.

Foi colocado uma estrutura de efeitos dentro do site para trazer um efeito suave para as coisas. Foi utilizado :Hover para efeitos de botão e nav.bar, transition e keyframes suave para a página inicial, transform para colocar um efeito de carregando para reservar o vinho, :before para adicionar um "◆" no inicio de lista, um "🍷" em todo h2 que gira, e um :active para dar efeito de clique no botão.
